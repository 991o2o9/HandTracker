
# HandTracker

A minimal Python project for real-time hand detection and tracking using your webcam.

This repository contains a small script (`handTrakcingMin.py`) that captures video from a camera, detects hands, and draws landmarks in real time.

Key points:

- Requirements: Python 3.7+ and the packages listed in `requirements.txt` (for example OpenCV and MediaPipe).
- Quick start: install dependencies and run the main script.

Try it:

```bash
pip install -r requirements.txt
python handTrakcingMin.py
```

Notes:

- If multiple cameras are connected, adjust the camera index in the script.
- Press `q` (or follow the script prompt) to stop the program.
